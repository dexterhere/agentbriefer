# Agentbriefer documentation

The Docusaurus source for `docs.agentbriefer.com`.

```bash
npm ci
npm run start
```

Production checks:

```bash
npm run typecheck
npm run build
npm run serve
```

User and contributor documentation lives in `docs/`. Stable release snapshots
live in `versioned_docs/`; do not edit a snapshot for changes that only apply to
the next release.
